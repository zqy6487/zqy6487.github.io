# Qiyun (Claire) Zheng

Personal academic website: https://zqy6487.github.io/

## Directory

- `index.html`: biography, research, leadership, honors, and interests.
- `assets/css/main.css`: typography, layout, and responsive styles.
- `assets/js/main.js`: section navigation highlighting.
- `assets/images/`: published portrait and favicon.
- `404.html`: missing-page response.
- `.nojekyll`: serve this website directly without a Jekyll build.
- `.gitignore`: keep local documents and temporary files out of Git.

## Editing

Edit the English text in `index.html`. Replace the portrait at `assets/images/portrait.png` when needed. Open `index.html` locally to preview; no installation or build is required.

GitHub Pages publishes the repository root on the `main` branch. Commits to that branch trigger publication.

Only website-ready files belong in this repository. Keep private resumes, original photographs, credentials, local deployment scripts, and document drafts outside it. A public repository also exposes its commit history; `.gitignore` does not remove previously committed files.
